## Отбор и файлы

- Крупнейшие фирмы отобраны из основного среза 2024 года по исходной положительной выручке, при равенстве — по ИНН. Числа сверены с batch 3. Ручных исключений нет.
- До трёх аномальных компаний на коллегу отобрано из сохранённой диагностики за 2017–2025. Сначала разные причины: скачок примерно в 1000 раз, пропадание выручки, `outlier`, расхождение баланса, активы без выручки, расхождение прибыли. Внутри причины — крупнейшая соответствующая сумма. Это ограниченный список кандидатов, не исчерпывающий поиск ошибок и не оценка ущерба.
- История выбранных ИНН извлечена заново из полной RFSD, включая годы регистрации вне ДФО и исключённые наблюдения. Пустой год явно отличается от строки с отсутствующей выручкой. Метка «В основном срезе» отражает правила отбора, а не наличие отчётности.
- `group_01_heads` … `group_08_heads` — топ-10 восьми групп; `group_09_heads` — «Прочее». Таблицы CSV/Parquet содержат признаки первого прохода, ранг, долю, регион, ОКВЭД, строки отчётности и флаги. ИНН/коды в CSV импортировать как текст.
- `assignments` — единое распределение; `cases` — основания отбора аномалий; `history` — 1 095 строк ИНН–год; `sector_history` — агрегаты 2011–2025; `coverage` — плановый охват. `review_0.csv` — семь случаев координатору, включая ЦРБ. `review_1.csv` … `review_5.csv` — тот же формат ответа для работы без Excel.

Передавайте коллегам [архив](../outputs/runs/20261003-batch6-audit-v2/audit_packet.zip): задание, пять Excel и два общих графика; материалы координатора — в отдельной папке. В Excel исходные суммы показаны в млн руб., исходные CSV/Parquet сохраняют тыс. руб. Полные исходники RFSD в архив не входят.

## Воспроизведение

```sh
uv run --locked python scripts/prepare_audit.py --audit-run outputs/runs/20261003-batch3-audit --figures-run outputs/runs/20261003-batch5-figures-v2
```

Команда требует только Polars. Проверяет хеши 15 исходных файлов, сохранённой диагностики и графиков, сверяет отраслевые суммы, создаёт новые CSV/Parquet, задание и графики, затем индексирует запуск. Основной код не зависит от Excel. Оформленные Excel текущего комплекта созданы отдельно; его `build_workbooks.mjs` и `packets.json` сохранены для повторного экспорта через установленный `@oai/artifact-tool`. Обычный повтор Python-команды не создаёт XLSX.

Результаты: [каталог](../outputs/runs/20261003-batch6-audit-v2/), [манифест](../outputs/runs/20261003-batch6-audit-v2/manifest.json). Перед заполнением сделайте рабочую копию Excel: индексированный комплект сохраняем неизменным. Полученные от коллег предложения не применяются автоматически. Координатор проверяет источник и год, затем отдельно вносит подтверждённое решение в `data/decisions.csv`.
