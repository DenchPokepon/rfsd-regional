Все последующие успешные запуски трёх аналитических скриптов и генератора графиков автоматически регистрируются в [машинном индексе](../outputs/index.json). По умолчанию создаётся новый каталог с временем UTC; `--output-dir` позволяет задать своё имя, но существующий каталог использовать нельзя. Незавершённые запуски не регистрируются. Пустой каталог `20261003-batch4-comparison` относится к остановленной проверке нулевого индекса S; результатов в нём нет. Первая версия `20261003-batch5-figures` сохранена как промежуточная: в `v2` исправлена цветовая легенда топ-5/топ-10 и уточнены подписи.

В каждом каталоге есть `manifest.json`: параметры, версии источников, Git HEAD на момент сохранения, контрольные суммы кода и всех файлов. При незакоммиченных изменениях один HEAD недостаточен для определения кода — используются также хеши файлов. Старые результаты перенесены без пересчёта; их манифест отдельно помечает архивирование и исходный коммит. Записки batch 3 и batch 4 дополнительно скопированы рядом с таблицами, чтобы сохранить именно ту редакцию, которая описывает запуск.

Машинные таблицы — Parquet (сохраняет типы ИНН и кодов) и CSV для обмена. Детальный состав batch 3 описан в [диагностике](data_audit.md#воспроизведение), batch 4 — в [сравнении](rfsd_vs_rosstat.md#источники-и-воспроизведение). Ни старые суммы, ни неподтверждённые ручные исправления не подмешиваются в новые расчёты.

Batch 5 сохраняет восемь таблиц, использованных в графиках, и хеши входных манифестов batch 3–4. Редакции трёх документов с графиками также скопированы в его каталог; исходные архивные записки batch 3–4 не перезаписаны.
