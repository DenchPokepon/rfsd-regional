# Передача проекта

Два основных документа: [задание коллегам](audit_task.md) и [краткий анализ RFSD–ВРП](rfsd_vs_rosstat_brief.md). [План](plan.md) и [индекс](results.md) сохраняют историю работы.

## Что передать

- Аналитикам — [комплект первого аудита](audit_packet.md): пять Excel, задание и графики. Координатор назначает имена вместо «Коллега 1–5»; каждый работает с копией своего файла.
- Для расчётов — репозиторий и [README](../README.md). Основной вход — `explore.py`, обычные Polars-запросы. RFSD скачивается отдельно; можно подключить существующий каталог через `RFSD_DATA_DIR`.
- Общий [архив передачи](../outputs/runs/20261003-batch8-handoff/handoff.zip) содержит код, документы и актуальные результаты batch 3–7. Исходной RFSD и Python-окружения в нём нет. Исторические промежуточные запуски остаются на исходном компьютере.

Ответ коллеги: таблица с источниками и решениями плюс устное заключение или короткое свободное ревью. Проверка первичной отчётности ещё не выполнена. Предложения об исключении координатор проверяет и записывает отдельно; архивные таблицы и Excel сохраняются неизменными.

## Границы воспроизведения

README содержит полный порядок пересчёта в новом клоне: диагностика → отраслевые срезы → Росстат → графики → списки аудиторам. Результаты каждого запуска сохраняются в новый каталог. Исторические Markdown-документы автоматически не переписываются; обычный Python-запуск создаёт CSV/Parquet, оформленные Excel уже включены в комплект.

RFSD берётся из закреплённой ревизии, Росстат — по закреплённым SHA-256. Публичный URL Росстата может со временем вести на новую редакцию: загрузчик остановится при несовпадении. Для точного повтора храните использованную копию исходников.

## Проверка batch 8

Протокол: [каталог](../outputs/runs/20261003-batch8-handoff/). Проверка выполнена в отдельном клоне и новом окружении (Python 3.11.16, Polars 1.44.2, uv 0.12.7), с общей проверенной копией исходников. Полная RFSD повторно из сети не скачивалась; SHA-256 всех 15 файлов совпали. Три файла Росстата загружены заново и прошли проверку хешей.

25 тестов прошли, включая проверки на реальных источниках. Все 55 новых Parquet-таблиц совпали с сохранёнными результатами после сортировки строк (допуск для float: относительный `1e-10`, абсолютный `1e-5` в единицах столбца). Четыре PNG совпали побайтно. Списки аудиторам сохранили 66 компаний для коллег и семь для координатора. Собранный wheel установлен и проверен вне исходного каталога; в нём только код и метаданные.

Новые запуски отдельно сохранены и индексированы: [диагностика](../outputs/runs/20261003-batch8-reproduce-audit/), [срез 2024](../outputs/runs/20261003-batch8-reproduce-dfo/), [Росстат](../outputs/runs/20261003-batch8-reproduce-comparison/), [графики](../outputs/runs/20261003-batch8-reproduce-figures/), [списки](../outputs/runs/20261003-batch8-reproduce-packet/). Это контрольный повтор; документы и Excel batch 6–7 остаются текущим комплектом. Для передачи в архив включены текущие результаты batch 3–7 и протокол, без дублирования новых таблиц.

На этом Windows-компьютере `uv python install 3.11` загрузил Python, но завершился ошибкой создания ссылки на версию. Сам Python 3.11.16 работает; окружение создано с явным указанием интерпретатора. Первоначальная ошибка и успешные команды сохраняются в протоколе. README содержит такой вариант установки. Ветка 3.11 закреплена, patch-версия не фиксируется.
